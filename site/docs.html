仍未解决？提交问题反馈

右键 Windows 通知区域中的软件图标，选择「设置…」。下文按照设置窗口的九个页面编排：先说明选项，再说明相关操作和限制。大多数选项立即生效；字体、颜色等独立对话框需要点击「确定」。

快速开始

软件仅提供 64 位 Windows 版本。推荐使用 Windows 11；Windows 10 22H2 的核心功能基本可用，但任务栏防遮挡存在兼容性问题，沉浸模式与 Dock 模式尚未在该版本实机验证。音频频谱要求 Windows 10 2004 或更高版本。

  1. 下载安装。从 GitHub Releases 或 Gitee Releases 下载安装包。国内网络可优先选择 Gitee。安装后运行 QQMusicLyric.exe。
  2. 配置播放器。QQ 音乐需要开启 SMTC；网易云音乐需要安装 BetterNCM 和 InfLink-rs，具体步骤见下一章。
  3. 播放音乐。打开已配置的桌面播放器并播放歌曲，封面、歌曲信息和歌词会自动显示在任务栏。两个平台同时运行时，软件会根据当前媒体会话和播放状态自动选择来源。
  4. 调整显示。右键托盘图标进入「设置…」，选择展示模式、字体、歌词颜色和其他功能。需要登录 Windows 后自动运行时，在托盘菜单勾选「开机自启动」，无需管理员权限。
先确认软件仍在运行

关闭歌词显示不会退出软件。需要完全退出时，使用托盘菜单中的「退出」；误选「完全停止」性能模式也会隐藏任务栏歌词。

配置音乐播放器

QQ 音乐桌面版

在 QQ 音乐自身设置中开启「显示系统媒体传输控件（SMTC）」，然后播放歌曲。如果软件已经运行但仍未识别，重启 QQ 音乐和 QQMusicLyric.exe 后重试。已测试 QQ 音乐 2252～2276 版本。

网易云音乐桌面版

网易云音乐官方 SMTC 信息没有可靠的播放进度，需要 InfLink-rs 补充歌曲 ID 和时间轴。适配可用性受 BetterNCM、InfLink-rs 与网易云客户端版本影响。

  1. 从 BetterNCM Installer 下载并安装 BetterNCM。
  2. 打开网易云音乐的 BetterNCM 插件商店，搜索并安装 InfLink-rs。插件商店不可用时，可从 InfLink-rs Releases 下载并手动安装。
  3. 按提示重启网易云音乐，再运行或重启 QQMusicLyric.exe。
不要混用插件

只安装 InfLink-rs，不要同时安装旧版 InfLink。酷狗音乐目前未适配；酷狗歌词仅作为手动搜索的候选来源。

设置参考

选项名称与软件界面保持一致。选项呈灰色时，请先检查当前展示模式、任务栏方向、性能模式及歌曲状态。

点击设置窗口左上角的「搜索设置」，或按 Ctrl+F 打开搜索面板。可搜索设置名称、选项或说明，支持用空格分隔多个关键词。点击结果跳转到对应设置，也可用方向键选择、回车跳转，按 Esc 关闭搜索面板。

左侧导航栏底部固定提供「文档中心」「问题反馈」「关于与更新」入口，分别打开在线使用文档、反馈页面和软件关于窗口；最下方显示当前安装版本。

显示

对应「设置 → 显示」，管理任务栏与窗口主题、通用字体、歌曲信息、封面、右键菜单，以及所有任务栏内容背景。

主题

任务栏内容主题
可选「系统、应用、浅色、深色」。「系统」和「应用」分别跟随 Windows 的系统模式与应用模式，控制任务栏内的歌词和相关信息。
对话框与悬浮窗主题
同样可选「系统、应用、浅色、深色」，独立控制设置等普通对话框与悬浮窗，不改变任务栏内容。

字体、歌曲信息与封面

通用字体
点击「选择字体…」，搜索本机字体，设置字号，并选择常规、加粗、斜体或粗斜体。可实时预览。这里影响任务栏歌词、每日一言、歌曲信息、沉浸模式时间／日期，以及 Dock 和内嵌模式的资源监视，不影响设置窗口等界面字体。资源监视也遵循所选字体样式，常规样式不会额外加粗。
显示歌曲信息
控制歌名、歌手等歌曲信息；侧边任务栏的竖向模式下固定关闭。
显示专辑封面
控制封面是否显示。关闭封面后，平台图标和封面效果也无法设置。
显示平台图标
在专辑封面右下角显示 QQ 音乐或网易云音乐图标，便于识别当前播放平台。
专辑封面效果
可选「默认」或「黑胶唱片」。黑胶封面播放时旋转，暂停时停在当前角度；极简模式下固定为默认效果。

菜单交互

右键显示任务栏歌词菜单
控制任务栏歌词区域的精简右键菜单。关闭后仍可通过托盘图标右键打开完整菜单。

背景效果

播放进度背景
从窗口左缘到歌词右缘，按歌曲进度填充专辑主题色；没有封面时使用系统强调色。与频谱的「背景波浪」互斥，极简模式下不可用。
进度背景不透明度
范围为 0～100%，仅在播放进度背景开启时可调。
任务栏内容背景
可选「无、封面模糊、纯色」。封面模糊将专辑封面高斯模糊后铺满；纯色跟随任务栏深浅色。该背景位于最底层，可与播放进度背景或背景波浪叠加。
封面背景不透明度
范围为 0～100%，仅在选择「封面模糊」时可调。
任务栏内容动态背景
可选「无、落叶、闪烁星星、二进制、流光粒子」。独立频谱容器与悬浮卡片不使用该效果，极简模式下暂时关闭。
动态背景作用范围
可选「都不启用、仅待机内容启用、仅歌词启用、都启用」。待机内容包括每日一言和默认欢迎语；只有先选择一种动态背景后才能设置范围。

展示模式

选择歌词显示在原任务栏内、覆盖原任务栏，还是放在独立顶栏或底栏。也可从托盘菜单的「展示模式」切换。

任务栏歌词展示模式

内嵌
在主显示器任务栏的空闲区域显示封面、歌曲信息和歌词，封面与歌曲信息可在「显示」页关闭。可选资源监视和频谱，不占用额外桌面工作区。
沉浸
覆盖所选的横向任务栏，歌词以整条任务栏中心为锚点。封面和歌曲信息位于左侧，固定操作区提供播放、音量、返回内嵌和完整菜单；右侧为频谱区域和时间日期。频谱是否显示仍由频谱开关与性能模式决定。
Dock 模式
在目标显示器顶部或底部显示独立横栏，并为桌面窗口预留工作区。提供歌词、播放操作、返回内嵌、快捷应用及完整菜单；右侧显示频谱和资源监视，不显示沉浸模式的时钟。
沉浸模式的前提

需要存在播放器媒体会话，且目标任务栏为横向。歌曲暂停不等于媒体会话消失。会话消失后回到主显示器内嵌布局；单选侧边任务栏时使用内嵌布局，选择全部显示器时仅覆盖横向任务栏。

显示器、位置与背景

目标显示器
沉浸与 Dock 模式可选择单台或全部显示器。内嵌固定使用主显示器；沉浸选择全部时只覆盖横向任务栏。目标显示器断开后切回主显示器。
Dock 位置
可选「顶部」或「底部」。Dock 会通过 Windows AppBar 占用对应工作区，不只覆盖在桌面之上。
沉浸模式背景
「调整方式」可选「模糊程度」或「不透明度」，随后用 0～100% 滑块调整。模糊从清晰桌面过渡到完全模糊；不透明度从全透明过渡到随 Windows 应用主题变化的纯底色。
Dock 背景
同样支持模糊程度或不透明度及 0～100% 调节，与沉浸背景分别保存。切换到对应模式后才能调整；如果背景初始化失败，相关选项会禁用，可打开运行日志查看原因。

资源监视

固定基础指标为系统 CPU 和内存；网络下行、网络上行、GPU 使用率和 CPU 频率为可独立开关的扩展指标，依次补位，超过一页时可在资源区域滚动鼠标翻看。Dock 自带资源区；横向内嵌需要单独开启，沉浸模式不显示资源区。

内嵌模式显示资源监视
在横向任务栏的内嵌模式右侧显示 CPU、内存及已开启的扩展指标。
显示下行速度
默认开启，显示系统网络接收速率。关闭后由后续指标补位，没有其他扩展指标时释放对应宽度。
显示上行速度
默认开启，显示系统网络发送速率。与下行速度独立控制；关闭后同样由后续指标补位，没有其他扩展指标时释放对应宽度。
显示 GPU 使用率
在 Dock 资源区或已开启资源监视的内嵌模式中增加 GPU 指标。系统没有可用 GPU 性能计数器时显示「—」。
显示 CPU 频率
增加 CPU 当前频率指标，例如「频率: 3.6GHz」。系统未提供当前频率时显示「—」。GPU 与 CPU 频率属于扩展指标，可在资源区域滚动鼠标翻看。

内嵌定位与自动避让

在「任务栏位置」中选择锚点，或按住左键拖动任务栏歌词。拖动时会出现吸附预览，松手后保存位置。软件会避开小组件、搜索、任务视图、应用图标、TrafficMonitor 和酷狗官方任务栏歌词；空间不足时会压缩或迁移，所有位置都放不下时自动隐藏，空间恢复后再显示。

沉浸与 Dock 操作

沉浸条的非按钮区域被鼠标悬停时会淡出，露出原任务栏供操作。鼠标离开任务栏且没有按住鼠标按键后再恢复。Dock 不使用这种让出交互；没有媒体会话且关闭空闲入口时，Dock 隐藏并释放工作区。

两种模式的返回按钮都切回内嵌模式；要结束程序，请在完整菜单中选择「退出」。Dock 快捷应用按钮使用「每日一言与更多」中配置的应用列表。

最大化窗口会避开 Dock 预留的工作区；真正的全屏应用打开时，Dock 按系统通知退到后方，退出全屏后恢复。

侧边任务栏与竖向歌词

Windows 11 任务栏位于左侧或右侧时，内嵌模式会改用窄栏封面、竖排歌词和纵向播放控件，沉浸模式不可用；Dock 是独立顶栏或底栏，不受任务栏方向影响。竖向模式下歌曲信息、双行歌词、横向歌词对齐、辅助歌词、资源监视和频谱不可用，每日一言固定左对齐，播放进度背景仍可使用。切回横向任务栏后，除已重置的频谱外，其余相关设置恢复可用。

性能

对应「设置 → 性能」，也可通过托盘菜单切换。性能模式只对本次运行有效，重启软件后恢复正常模式。

模式行为
正常按各功能开关显示歌词、转场、频谱、背景和悬浮卡片，不会自动开启已关闭的功能。
低渲染将播放动画限制在约 30 FPS，并暂停频谱捕获
完全停止隐藏任务栏歌词，停止帧定时器并释放 GPU 资源，但保留当前会话数据
极简保持正常歌词刷新率，仅保留基础歌词，关闭逐字高亮、转场、频谱、附加背景、媒体卡片和切歌弹窗

从完全停止恢复时，先切换到其他性能模式，再确认任务栏歌词处于开启状态。切回正常模式后，频谱按原开关恢复；极简模式临时关闭的外观效果也按原配置恢复，不会清空偏好。

悬浮卡片

媒体卡片、每日一言和快捷启动卡片共用这里的展开方式、背景与文字颜色。卡片在内嵌模式使用；沉浸和 Dock 使用横栏上的固定控件，极简模式不展开卡片。

需要先保留空闲入口，或在「媒体控件」中开启播放控件并选择「媒体卡片」，相关卡片设置才可用。背景颜色、专辑色跟随和动态文字颜色仅在磨砂玻璃背景下可调。

悬浮卡片展开方式
「悬浮展开」需要鼠标在歌词区域停留片刻；「点击展开」可点击歌词区域任意位置立即打开。极简模式下不可用。
悬浮卡片背景
可选「纯色」或「磨砂玻璃」，三类卡片统一使用。
悬浮卡片背景颜色
点击颜色值打开取色器。磨砂背景未使用有效专辑色时，三类卡片共用该颜色；仅磨砂玻璃模式可设置。
磨砂玻璃颜色跟随专辑
播放且成功提取专辑主色时，磨砂卡片使用专辑色；没有播放时回退到自定义背景颜色。
磨砂卡片字体颜色动态变化
根据卡片背后内容的明暗自动切换黑色或白色文字，同时作用于媒体卡片、每日一言和快捷启动卡片。

媒体控件

管理内嵌模式的播放操作。歌曲是否支持上一首、下一首等操作取决于当前播放器提供的控制能力。

显示播放控件
开启后可在歌词区域使用播放控制。沉浸和 Dock 模式自带固定控制区，因此该设置在这两种展开模式下不可用。
控件样式
「内嵌控件」在鼠标悬浮时显示，提供播放操作；「媒体卡片」还显示歌曲进度，其展开方式由「悬浮卡片」页决定。点击卡片中的应用图标或名称可打开播放器。只有显示播放控件且非极简模式时可选择。

播放操作与媒体卡片

内嵌控件和媒体卡片都支持上一首、播放／暂停和下一首。媒体卡片额外显示封面、当前进度和总时长。音量按钮可展开应用音量滑块，支持拖动、滚轮和静音；音量只作用于当前音乐应用，不改变系统主音量。

沉浸与 Dock 模式使用自身固定的控制区，不需要另行开启这里的播放控件。切歌提示的时长、位置和全屏应用行为可在「切歌弹窗」中设置。

频谱

对应「设置 → 频谱」，控制当前 QQ 音乐或网易云音乐进程的音频频谱。侧边任务栏和极简模式下不可用，低渲染与完全停止模式会暂停捕获。

频谱
频谱总开关，开启后才能设置配色与样式。
频谱颜色
可选「跟随已播放色、跟随专辑主题色、自定义颜色」。自定义颜色作为频谱基色。
自定义频谱颜色
点击颜色值选择颜色，仅在选择「自定义颜色」时生效。
频谱样式
可选「默认、柱状图、梦幻波浪」。样式不同，频谱在内容区的呈现方式也不同。
频谱渐变色
基于当前频谱颜色生成渐变配色，不控制频谱区域的宽度。
背景波浪
将梦幻波浪用作歌曲信息和歌词背景，仅在频谱开启且选择「梦幻波浪」时可开启。与播放进度背景互斥。
背景波浪不透明度
范围为 0～100%，仅在背景波浪实际开启时可调。

频谱只捕获当前 QQ 音乐或网易云音乐进程的音频，不受其他软件发声影响。播放器更换输出设备或重启后，软件会重新绑定音频会话。

歌词

对应「设置 → 歌词」，管理歌词排版、颜色与效果、辅助歌词和 QQ 音乐本地歌词。

排版、颜色与效果

双行歌词
当前行没有正在显示的翻译或罗马音时，额外预览下一行。当前行已有辅助歌词时优先显示辅助歌词，不再叠加下一行。竖向任务栏下不可用。
歌词对齐
可选「左对齐、居中、右对齐」，仅内嵌模式的横向歌词可设置；展开模式使用自身布局，竖向模式使用竖排规则。
歌词字体颜色与效果
打开独立对话框，设置未播放颜色、已播放颜色、未播放不透明度（5～100%）、光晕颜色与开关、描边颜色与开关，并实时预览。开启「全局设置」后深浅色模式共用一套配置；关闭后可分别设置「深色模式」和「浅色模式」。点击「确定」才应用，取消或关闭不影响现有配置。
歌词已播放颜色跟随专辑
让已播放歌词颜色随专辑封面主色变化，优先级高于固定的已播放字体颜色。

翻译与罗马音

开启翻译/罗马音
控制辅助歌词总开关；竖向任务栏下固定关闭。
辅助歌词类型
可选「翻译」或「罗马音」。只有辅助歌词开启且当前歌曲存在可用内容时可切换；检查中会显示对应状态。

托盘菜单的「辅助歌词」可快速切换类型或关闭显示。逐字歌词按时间轴平滑填充，普通 LRC 按行显示；极简模式不使用逐字高亮。字体、字号和粗斜体在「显示 → 通用字体」中调整。

本地歌词

使用 QQ 音乐本地歌词
启用本地 QRC 索引与本地优先获取，仅用于 QQ 音乐。
记住歌词版本选择
按歌曲记住本地版或在线版选择。关闭后不保存新记录，但已经保存的记录仍会读取。
QQ 音乐本地歌词目录
点击「选择文件夹…」指定目录，程序会递归索引其中的歌词文件。只有启用本地歌词后可设置。

手动搜索与进度微调

自动匹配错误时，打开托盘菜单的「手动搜索歌词」。歌名和歌手会按当前歌曲自动填充，也可自行修改后搜索 QQ 音乐、网易云音乐或酷狗歌词候选。窗口打开期间切歌会更新目标歌曲，并清空旧候选和预览，需要重新搜索。

选择候选可预览逐字或逐行歌词；候选包含翻译或罗马音时，可在预览面板中独立切换显示。确认选择后，结果会按平台和歌曲标识保存，下次自动使用。对手动选择的歌词，可每次提前或延迟 0.5 秒，调整结果会持久化。

本地歌词的获取顺序

手动选词优先于自动匹配。启用本地歌词后，默认先找本地 QRC，未命中再获取在线歌词；有对应文件时合并翻译和罗马音。版本切换入口要求当前为 QQ 音乐、已配置本地目录、歌词已加载且不是手动选词结果。

切歌弹窗

对应「设置 → 切歌弹窗」，控制切歌时所选显示器上的圆角歌曲卡片。卡片显示圆角方形封面、歌名与歌手两行信息，磨砂背景带轻微专辑色和柔和阴影。弹窗固定开启鼠标穿透，点击会直接作用于下方窗口，不抢占焦点，无需额外设置。首次出现时宽度按文字长度在 220～280 DIP 间调整；同一显示器上连续切歌保持外框位置与宽度，只切换内部内容并重新计算停留时间。长文字短暂停留后滚动显示。

切歌时弹出歌曲信息
总开关，弹窗显示封面、歌名和歌手。极简模式下不可用。
切歌弹窗显示时长
范围为 1～10 秒，仅在弹窗开启时可调。
全屏应用时关闭弹窗
前台存在全屏应用时不弹出，减少对游戏、视频等内容的干扰。
显示器选择
可选「主显示器」或「当前鼠标所在显示器」，默认使用主显示器。每次弹窗出现时确定目标显示器，显示期间不会随鼠标移动；下次切歌或预览时重新确定。选择会保存，重启后继续使用。
切歌弹窗位置
可选「中上」或「中下」，弹窗位于所选显示器的对应位置。
预览切歌弹窗
点击「预览弹窗」，使用当前歌曲按所选显示器、位置和停留时间展示，无需切歌。需要开启切歌弹窗、当前有歌曲且不处于极简模式；预览同样保留鼠标穿透和全屏应用过滤。

每日一言与更多

管理没有播放器媒体会话时的任务栏内容、快捷启动和滴答清单。这里的空闲状态与歌曲暂停不同。

空闲内容

无播放时保留任务栏入口
控制没有播放器媒体会话时是否保留入口，播放器暂停不等于进入空闲状态。关闭后，没有媒体会话时隐藏入口；Dock 同时释放预留工作区。
空闲文字
可选「每日一言、欢迎语、不显示」。只有横向内嵌模式开启资源监视后，才能新选择「不显示」，此时保留资源区。启用滴答清单后，启动且没有媒体会话时仍可播报一次今日任务。
自定义欢迎语
选择「欢迎语」时生效，最多 20 个字符且不能为纯空格。留空则恢复根据时间和日期类型生成的默认欢迎语。
每日一言来源
可选「一言、今日诗词、网易云热评」。今日诗词会结合客户端网络 IP、时间等信息推荐，并在本地保存接口 Token；网易云热评通过一言的网易云分类获取。
每日一言更新频率
可选「每天、每 12 小时、每小时」，程序会缓存当前内容。
每日一言字体对齐方式
可选「左对齐、居中、右对齐」，同时影响任务栏与悬浮卡片中的每日一言，不影响正常歌词。竖向任务栏下固定左对齐。

快捷启动

编辑应用列表需要保留空闲入口，极简模式下不可编辑。Dock 的快捷应用入口复用同一列表。

可打开的应用
通过文件选择器添加本地 EXE，最多 10 个。可修改显示名称与路径、删除条目、拖动排序，并用统一开关控制名称显示。路径失效时条目会提示重新选择。点击条目启动应用，Dock 模式也可使用同一组快捷应用。

滴答清单

启用滴答清单
开启自动同步和快捷启动卡片中的今日任务入口。关闭只停止同步与入口，不会删除 API 口令。
API 口令
填写滴答清单网页版创建的普通用户 API 口令，只保存到 Windows 凭据管理器。
连接滴答清单
验证口令并读取今天的未完成任务；已连接时可重新连接。
同步今日任务
点击「立即同步」刷新任务。只有启用滴答清单并成功连接后可操作。
断开连接
删除本机保存的滴答清单 API 口令。

空闲卡片操作

保留空闲入口时，可按「悬浮卡片」设置的方式展开卡片，复制每日一言或启动应用。媒体卡片播放中还可切换到每日一言与快捷启动面板。宠物在展开横栏中随场景伴听、休息或漫游；内嵌模式的媒体卡片中原地伴听或休息。极简和完全停止模式不显示宠物。

首次连接与任务操作

  1. 打开 滴答清单网页版，在「设置 → 账号与安全 → API 口令」中创建并复制普通用户 API 口令。
  2. 在软件的「设置 → 每日一言与更多 → 滴答清单」中填写口令，连接后开启自动同步。无需安装滴答清单本地客户端。
  3. 没有播放器会话时，在空闲卡片切换到「今日任务」。点击任务打开网页详情，点击左侧复选框完成任务；「立即同步」可手动刷新。

托盘菜单与维护

右键通知区域的软件图标打开完整菜单；沉浸与 Dock 横栏的菜单按钮也打开同一菜单。歌词区域的右键菜单是精简版，是否显示由「显示」页控制。

开启／关闭任务栏歌词
只控制显示，不退出程序。完全停止模式下需要先切换其他性能模式。
手动搜索与辅助歌词
操作方法见「歌词」章节。切换本地／在线版本需要启用 QQ 音乐本地歌词、配置目录且当前不是手动选词；辅助歌词菜单仅在歌曲存在相关内容时出现。
开机自启动
登录当前 Windows 账户后自动运行，无需管理员权限。
检查更新…
菜单右侧显示当前安装版本，点击打开关于窗口，选择 GitHub 或 Gitee 更新源，检查版本、阅读更新日志、下载并安装更新。可开启启动时自动检查；安装更新时会退出当前程序。
运行日志
查看播放、歌词来源、封面来源和软件资源占用，切换查看封面图片。「选择位置」更改日志目录，「打开位置」打开目录；定期清理可选不清理或保留 7、30、90 天。
重启应用
正常退出当前进程后重新启动，保留已保存的设置；性能模式按启动规则恢复为正常。
退出
结束软件运行。与沉浸／Dock 横栏的返回内嵌按钮不同。

常见问题排查

播放歌曲后没有显示歌词

依次确认托盘菜单中的任务栏歌词已开启、性能模式不是「完全停止」，以及播放器配置符合前文要求。内嵌模式下，任务栏空间不足也会自动隐藏歌词；关闭不需要的任务栏按钮或其他任务栏插件后再观察。Windows 10 的防遮挡兼容性有限，可能出现重叠或隐藏异常。

网易云音乐没有歌曲或进度信息

确认安装的是 BetterNCM 与 InfLink-rs，而非旧版 InfLink，并在插件安装后重启网易云音乐和本软件。仍无法识别时，检查插件与当前网易云客户端版本是否兼容。

歌词匹配错误或时间不一致

使用托盘菜单的「手动搜索歌词」选择正确候选，再利用提前／延迟 0.5 秒微调时间轴。QQ 音乐启用本地歌词后，也可在本地版与在线版之间切换，比较哪个版本更准确。

频谱没有跳动

确认系统为 Windows 10 2004 或更高版本、当前播放器正在发声、频谱已开启，并使用「正常」性能模式。低渲染、完全停止和极简模式会暂停频谱，侧边任务栏的竖向模式也会关闭频谱。播放器更换输出设备或重启后，可稍等软件重新绑定音频会话。

沉浸模式没有出现

确认存在活动音乐会话并使用横向任务栏。单独选择侧边任务栏时按内嵌布局显示；选择全部显示器时，沉浸模式只覆盖横向任务栏。

设置没有保存或程序行为异常

检查软件弹出的设置文件读写提示，确认当前 Windows 账户对配置目录具有访问权限，且文件没有被其他程序占用。随后打开「运行日志」查看详细事件；需要协助时，前往意见反馈，说明系统版本、播放器版本、所用展示模式和问题复现步骤。
