## 项目核心功能

- **任务栏内嵌歌词**：窗口作为任务栏（Shell_TrayWnd）的子窗口，外观贴近 Windows 11 原生媒体卡片——左侧圆角封面 + 歌名/歌手，右侧当前行歌词（超长自动滚动），支持 QQ 音乐和网易云音乐，切歌时歌词内容平滑过渡
- **四边任务栏与竖向歌词（预览）**：Windows 11 26H2 支持任务栏位于上、下、左、右四个位置
- **多格式歌词与逐字高亮**：支持逐字时间轴歌词；逐字歌词按像素进度平滑填充并滚动，LRC 保持整行高亮；当前歌曲没有可用翻译或罗马音时，可选双行歌词，同时显示当前行与下一行预览
- **翻译与罗马音**：可显示部分外文歌曲的翻译或罗马音，并可从设置窗口启用、关闭及切换显示类型
- **QQ 音乐本地歌词**：在设置中选择 QQ 音乐本地歌词目录后，程序递归索引本地 QRC 缓存；手动保存的歌词优先，默认按本地→在线获取，本地未命中自动回退在线；托盘菜单可在本地版与在线版之间切换，并可按歌曲持久化选择
- **双平台自动识别**：同时运行 QQ 音乐和网易云音乐时，根据 Windows 当前媒体会话及播放状态自动选择正在播放的来源；切换平台时同步切换歌曲、歌词和控制目标
- **每日一言与空闲入口**：未检测到音乐播放器会话时可保留任务栏入口，显示来自一言或今日诗词的每日一言；支持每天、每 12 小时或每小时更新，缓存当前内容、左/中/右对齐和一键复制，悬浮时显示复制提示并在成功后反馈状态；关闭每日一言后改为按时间与日期类型生成默认欢迎语，每日一言与任务栏歌词之间使用平滑上下转场
- **快速打开应用**：空闲页面提供快速打开区域，可从设置添加本地应用程序地址，最多添加 10 个，支持自定义名称、名称显示开关、点击启动、拖动排序和滚动查看；快速打开区域可展开/收起，并与每日一言、悬浮媒体卡片平滑切换
- **悬浮播放控件与媒体卡片**：开启悬浮播放控件后，可选择在歌词区内嵌显示「上一首 / 播放暂停 / 下一首」，或在任务栏外展开独立媒体卡片；媒体卡片显示播放器图标/名称、封面、歌名/歌手、当前进度、总时长和进度条，支持纯色或磨砂玻璃背景，磨砂背景可跟随专辑主色渐变并根据背景明暗自动适配文字颜色，展开/收起和切歌均有平滑过渡，点击播放器图标或名称可打开对应音乐软件；播放中可切换到「每日一言 + 快速打开」组合面板，三类卡片共用展开方式、背景、专辑色跟随和自动适配文字颜色设置
- **应用音量独立调节**：内嵌控件新增音量按钮，悬停弹出音量滑块浮窗；媒体卡片内置音量图标与可展开滑块；通过 WASAPI 音频会话单独调节 QQ 音乐/网易云音乐的音量（对应音量合成器中该应用的一格），不影响系统主音量，支持拖动、滚轮调节和静音
- **切歌浮窗提示**：切歌时在主屏幕中下方（可选中上方）短暂弹出封面、歌名和歌手；弹窗磨砂半透明、置顶，依据背后内容明暗自动适配文字颜色，滑入滑出平滑过渡；可设置停留时长（1~10 秒）、弹出位置，以及前台有全屏应用时不弹出
- **任务栏歌词背景**：可选择无背景、封面模糊（专辑封面高斯模糊后铺满，不透明度可调）或纯色（跟随任务栏深浅色）；背景画在最底层，可与播放进度背景、背景波浪叠加
- **播放进度背景**：从窗口左缘到歌词右缘按播放进度填充专辑主题色（无封面时回退系统强调色），不透明度可调；与频谱的背景波浪互斥
- **音频频谱**：跟随当前播放器（QQ音乐/网易云音乐，其他软件出声不受影响）播放跳动的频谱，可在设置窗口选择默认、柱状图或梦幻波浪样式；梦幻波浪可作为歌曲信息和歌词背景并调节透明度，频谱颜色跟随已播放歌词颜色，开启时窗口自动加宽、关闭即恢复
- **任务栏内容动态背景**：提供落叶、闪烁星星、二进制和流光粒子四种动态效果，可选择仅每日一言、仅歌词或两者显示；独立频谱容器和悬浮卡片不使用该效果，极简模式下关闭
- **性能模式**：在设置窗口切换「正常 / 低渲染 / 完全停止 / 极简」；低渲染将播放动画限制在约 30 FPS 以降低 GPU/CPU 占用，完全停止会隐藏任务栏歌词、停止帧定时器并释放 GPU 资源，但保留当前会话数据，恢复后立即还原；极简模式保持正常歌词刷新率，保留基础歌词显示并将封面效果固定为方形，关闭逐字高亮、转场、频谱、附加背景、媒体卡片和切歌弹窗；低渲染、完全停止和极简模式下频谱捕获自动暂停，切回正常模式后恢复，性能模式仅对本次运行有效，重启后恢复正常
- **双锚定位 + 自动避让**：歌词可锚定在「通知区域左侧」或「任务栏最左侧」。Windows 11 下可自动避开小组件、搜索、任务视图和应用图标；空间不足时原位收缩，仍放不下则自动换到容得下的空闲区。Windows 10 22H2 已测试基本可用，但任务栏防遮挡目前存在兼容性问题
- **外观自定义**：字体、字号、粗体/斜体、歌词颜色、逐字未播放色与不透明度、光晕/描边（颜色独立可调），横向歌词支持左/中/右对齐，左右侧竖向歌词按竖排规则显示，设置持久化；字体颜色与效果支持全局共用或按深色/浅色模式分别配置，已播放色可一键跟随专辑封面主色调
- **Fluent/Mica 对话框**：设置、字体选择、字体颜色与效果、颜色选择、手动搜索歌词和关于窗口统一采用 Windows 11 Fluent 风格，在支持的系统上使用 Mica 材质；任务栏歌词与对话框/悬浮窗可分别跟随系统、跟随应用或固定为浅色/深色，相关对话框支持手动调整大小并保持最小尺寸与布局比例，设置页部分选项提供与实际界面对应的示意预览，高刷新率下拖动设置窗口时自动使用静态快照，减少拖动延迟
- **手动搜索歌词**：自动匹配错误时可手动搜索并选择正确版本，支持 QQ 音乐、网易云音乐和酷狗歌词候选；对话框可预览逐字滚动或逐行歌词，候选包含翻译或罗马音时可在预览面板独立切换显示；选择结果按平台和歌曲标识分别持久化，下次自动命中
- **更新检查与安装**：关于窗口可选择 GitHub 或 Gitee 作为更新源，查看更新日志、下载并安装更新；开启启动时自动检查后，发现新版本会弹出提示，可直接跳转发布页或进入更新流程
- **运行日志**：托盘菜单可打开运行日志面板，查看当前播放、歌词来源、封面加载、CPU/GPU 与专用内存等状态，并可切换查看已成功加载的封面图片；详细运行事件（包括歌词请求与来源、手动搜索、设置/托盘/播放控制、音量、更新，以及资源创建与释放）按会话写入日志文件，并可选择保存目录和定期清理周期
- **开机自启动**：可通过托盘菜单设置随 Windows 登录自动运行，无需管理员权限
- **歌曲信息和封面隐藏**：通过设置窗口设置隐藏歌名、歌手、专辑信息或专辑封面
- **平台识别图标**：可在专辑封面右下角显示当前播放平台图标，便于区分 QQ 音乐和网易云音乐
- **专辑封面效果**：可在默认圆角方形封面与黑胶唱片效果之间切换；黑胶唱片在播放时旋转，暂停时保持当前位置
- **手动调整歌词进度**：对于手动搜索的歌词支持手动提前或者延迟 0.5 秒并持久化
- **未检测到播放器时的任务栏入口**：可在设置中保留或隐藏空闲入口；保留时未检测到音乐播放器会话会显示每日一言或默认欢迎语及快速打开应用，关闭后隐藏任务栏入口

## 工作原理

- **播放状态**：通过 Windows SMTC（System Media Transport Controls）监听已适配的播放器会话。QQ 音乐按 `SourceAppUserModelId=QQMusic.exe` 识别；网易云音乐目前按 InfLink-rs 写入 SMTC `Genres` 的 `NCM-{歌曲ID}` 标识识别。两个平台分别处理时间线和暂停/恢复逻辑，避免互相复用进度状态
- **歌词来源**：QQ 音乐手动保存的歌词优先；启用本地歌词时默认先匹配本地 QRC，未命中再按酷狗 KRC 逐字歌词、QQ 音乐 QRC 逐字歌词和 QQ 音乐 LRC 逐行歌词的在线链路获取，也可从托盘菜单切换到在线版；本地 QRC 对应的原文、翻译和罗马音文件会合并显示。网易云音乐按歌曲 ID 优先获取 YRC 逐字歌词，失败后回退网易云 LRC 逐行歌词。命中后会查询可用的翻译与罗马音，内置 LRU 缓存避免重复请求
- **音频频谱**：WASAPI 进程级回环捕获（`ActivateAudioInterfaceAsync`，根据当前来源捕获 `QQMusic.exe` 或 `cloudmusic.exe` 进程树，Win10 2004+ 原生支持，无驱动无注入）→ 1024 点 FFT（50% 重叠）→ 60Hz~14kHz 对数分 12 频段 →「上升立即、下降平滑」后 60fps 渲染
- **SMTC 适配结构**：QQ 音乐和网易云音乐使用独立的播放器适配器，公共层只负责会话监听、来源选择和控制转发，便于后续增加其他播放器

## 项目技术栈

| 层 | 技术 |
| --- | --- |
| 语言 / 标准 | C++20（MSVC） |
| 窗口 / 渲染 | Win32 分层窗口（UpdateLayeredWindow）、DirectComposition、Direct2D、DirectWrite |
| 系统接口 | C++/WinRT（SMTC）、WASAPI 进程级回环捕获、UI Automation（任务栏按钮避让） |
| 网络 / 数据 | libcurl、nlohmann/json、zlib |
| 构建 | CMake + Ninja + vcpkg |

程序本体以单可执行文件交付，无 Electron / 无 Node / 无托管代码。

## 构建

1. 准备环境：Visual Studio 2022（MSVC + Windows SDK）、[vcpkg](https://github.com/microsoft/vcpkg)、CMake ≥ 3.25、Ninja
2. 安装依赖（vcpkg，triplet `x64-windows`）：
   ```bash
   vcpkg install curl nlohmann-json zlib
   ```
3. 命令行构建（Ninja）：
   ```bash
   cmake -S . -B build -G Ninja ^
     -DCMAKE_TOOLCHAIN_FILE=<vcpkg 根目录>/scripts/buildsystems/vcpkg.cmake ^
     -DVCPKG_TARGET_TRIPLET=x64-windows -DCMAKE_BUILD_TYPE=Release
   cmake --build build
   ```
   也可以用 Visual Studio 2022 直接「打开本地文件夹」，在 CMake 设置中指定 `CMAKE_TOOLCHAIN_FILE` 和 `VCPKG_TARGET_TRIPLET=x64-windows` 后构建。

## 使用

1. 运行 `QQMusicLyric.exe`，再打开 QQ 音乐或网易云音乐播放歌曲，歌词会自动出现在任务栏上
2. 右键托盘图标：
   - **开启/关闭任务栏歌词**：显示或隐藏任务栏歌词
   - **任务栏位置**：通知区域左侧 / 任务栏最左侧（适配开始菜单居中的布局）
   - **手动搜索歌词**：自动匹配不准时手动选词，支持手动提前或者延迟0.5秒并持久化
   - **切换歌词版本**：启用 QQ 音乐本地歌词并命中歌词后，可在本地版与在线版之间切换；在设置中开启「切换版本持久化」后会按歌曲记住选择
   - **设置…**：打开设置窗口，集中调整显示、性能、悬浮卡片、悬浮媒体控件、频谱、歌词、切歌弹窗及每日一言与应用速启
   - **开机自启动**：登录 Windows 时自动运行（写入 HKCU Run 注册表项）
   - **关于**：查看版本信息、选择 GitHub/Gitee 更新源、查看更新日志、检查并安装 Release 更新，以及设置启动时自动检查；检测到新版本时会弹出更新提示
   - **运行日志**：查看当前播放、歌词来源、封面加载和资源占用状态，可切换预览已加载的封面图片，打开日志目录或设置日志保留周期
   - **退出**：退出程序
3. 在 **设置…** 窗口中：
   - **显示**：设置任务栏内容与对话框/悬浮窗的系统、应用、浅色或深色主题，选择通用字体，显示/隐藏歌曲信息、专辑封面和平台图标，选择默认或黑胶封面效果，选择任务栏内容背景（无 / 封面模糊 / 纯色）并调节封面模糊不透明度，开启播放进度背景并调节其不透明度，选择任务栏动态背景效果及其作用范围，部分选项可直接查看示意预览
   - **性能**：选择正常 / 低渲染 / 完全停止 / 极简；极简模式保留基础歌词和正常刷新率，关闭逐字高亮、转场、频谱、附加背景、媒体卡片和切歌弹窗；性能模式仅对本次运行有效
   - **悬浮卡片**：设置媒体卡片、每日一言和快速打开卡片的展开方式（悬浮 / 点击）、背景（纯色 / 磨砂玻璃）、背景颜色预览、磨砂背景跟随专辑主色和自动适配文字颜色
   - **悬浮媒体控件**：设置悬浮时是否显示播放控件，以及使用歌词区内嵌控件还是独立媒体卡片
   - **频谱**：开启/关闭频谱，选择默认、柱状图或梦幻波浪样式；梦幻波浪可作为歌曲信息和歌词背景，并调节背景不透明度（与播放进度背景互斥）
   - **歌词**：开启双行歌词，选择左对齐/居中/右对齐，设置歌词字体颜色与效果，设置已播放颜色是否跟随专辑，开启翻译/罗马音并切换辅助歌词类型；启用 QQ 音乐本地歌词、选择本地歌词目录并设置切换版本持久化
   - **切歌弹窗**：设置开关、停留时长、位置和前台全屏应用时是否弹出
   - **每日一言与应用速启**：设置是否保留未检测到音乐播放器会话时的任务栏入口、是否显示每日一言、来源（一言 / 今日诗词）、更新频率和对齐方式；在快速打开区域添加本地 EXE、编辑名称、显示/隐藏名称、拖动排序或删除应用，最多 10 个
4. 鼠标悬浮歌词区域可显示播放控制按钮（可在设置中选择关闭，默认开启）；选择「媒体卡片」时会展开独立卡片（可选悬浮或点击展开），显示播放器和歌曲播放进度，点击卡片顶部的播放器图标或名称可打开对应音乐软件，播放中还可切换到「每日一言 + 快速打开」组合面板，切歌和页面切换均有平滑过渡；在每日一言页点击复制按钮可复制内容，快速打开区域可通过箭头展开或收起；悬浮内嵌控件的音量按钮或媒体卡片的音量图标，可拖动滑块单独调节音乐应用音量，不影响系统主音量

> QQ 音乐桌面版（`QQMusic.exe`）需要在 QQ 音乐设置中打开“显示系统媒体传输控件（SMTC）”；网易云音乐桌面版需要先按下方说明安装 BetterNCM 和 InfLink-rs。仅支持 64 位 Windows；Windows 10 22H2 已测试，除任务栏防遮挡外其余核心功能基本正常（频谱功能需 Windows 10 2004 及以上）。

### 竖向模式限制

当 Windows 任务栏位于左侧或右侧时，程序会自动进入竖向模式。为保证窄栏中的内容可读，以下设置会在设置窗口中禁用，竖向期间无法开启或切换：

- **显示歌曲信息**：固定关闭
- **双行歌词**：固定关闭
- **歌词对齐**：由竖排布局接管，横向的左对齐 / 居中 / 右对齐选项不可切换
- **翻译/罗马音**：辅助歌词总开关固定关闭，「翻译 / 罗马音」类型不可切换
- **频谱相关设置**：频谱总开关固定关闭，频谱样式固定为「默认」，背景波浪固定关闭，背景波浪不透明度不可调节；切换到竖向时，频谱会关闭并保持关闭，样式重置为默认并保存
- **每日一言字体对齐方式**：固定为左对齐，左对齐 / 居中 / 右对齐选项不可切换

播放进度背景不属于频谱功能，竖向模式下仍可单独开启。除频谱外，歌曲信息、双行歌词、歌词对齐和辅助歌词相关设置会在切回横向任务栏后恢复可用。

## 网易云音乐适配

网易云音乐桌面版需要额外的 SMTC 增强插件才能提供歌曲 ID 和可靠的播放进度。使用网易云音乐前必须安装 BetterNCM 和 InfLink-rs：

1. 从 [BetterNCM Installer](https://github.com/std-microblock/BetterNCM-Installer/releases/latest) 下载并安装 BetterNCM。
2. 打开网易云音乐的 BetterNCM 插件商店，搜索并安装 **InfLink-rs**。
   > 如果插件商店不可用，也可以从 [InfLink-rs Releases](https://github.com/apoint123/inflink-rs/releases/latest) 下载插件后手动安装。
3. 按提示重启网易云音乐，再运行或重启 `QQMusicLyric.exe`。

> 只安装 **InfLink-rs**，不要同时安装旧版 InfLink。网易云适配的可用性受 BetterNCM、InfLink-rs 以及网易云音乐客户端版本影响，不保证所有版本均可用。

## 适配与功能提示
